# ABCD Workout Tracker

אפליקציית מעקב אימונים בעברית (RTL) עם עיצוב מודרני ויכולות מתקדמות:

- ניווט מהיר בין סקירה / היסטוריה / תוכנית.
- מצב אימון מלא (Overlay) עם מעקב סטים.
- שינוי משקל וחזרות בגלגלות (select wheel) במקום הקלדה חופשית.
- טיימר מנוחה בין סטים.
- סטטיסטיקות חכמות: יעד שבועי, רצף אימונים, שיאים אישיים ונפח שבועי.
- פעולות מהירות: העתקת משקלים מהאימון הקודם, ייצוא/ייבוא גיבוי.
- ניהול תרגילים (הוספה / עריכה / מחיקה) עם שדות גלגלת.
- תמיכה ב-PWA.

## הרצה מקומית

```bash
python3 -m http.server 8080
```

ואז לפתוח: `http://localhost:8080/index.html`
