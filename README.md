# Lift It Workout Tracker

אפליקציית מעקב אימונים בעברית (RTL) עם פיצ'רים מתקדמים:

- סקירה/היסטוריה/תוכנית/סטטיסטיקה/הגדרות.
- גרף נרות לכל תרגיל עם היסטוריית משקלים.
- תזכורת "כמה זמן לא העליתי משקל" לכל תרגיל.
- הזנת אימוני עבר ידנית + ניסיון פענוח תמונת טבלת עבר (OCR).
- בחירת גודל פונט, שפה (עברית/אנגלית) ומצב כהה/בהיר.
- מצב אימון עם גלגלות למשקל/חזרות, טיימר מנוחה, וניהול תוכנית.
- ייצוא/ייבוא גיבוי JSON.

## הרצה מקומית

```bash
python3 -m http.server 8080
```

ואז לפתוח: `http://localhost:8080/index.html`
