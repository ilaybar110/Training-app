# ABCD Workout Tracker

האפליקציה עודכנה לעיצוב ולממשק בסגנון שביקשת:

- מסך עליון עם CTA גדול להתחלת אימון.
- טאבים: סקירה, היסטוריה, תוכנית.
- מצב אימון מלא (Overlay) עם מעבר בין תרגילים וסטים.
- טיימר מנוחה בין סטים.
- ניהול תרגילים (הוספה, עריכה, מחיקה).
- היסטוריית אימונים וסטטיסטיקות התקדמות.

## הרצה מקומית

```bash
python3 -m http.server 8080
```

ואז לפתוח: `http://localhost:8080/index.html`
